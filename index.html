03 / DATA ENGINEERING

The Polite Scraper

Data pipeline

The problem. Repeatedly downloading unchanged catalogue pages wastes requests and makes a small data collection job less efficient.

What I did. I selected a lightweight requests-and-BeautifulSoup approach because the target is server-rendered HTML, then added request delays, timeouts, SHA-256 caching and Pydantic validation.

What came of it. The recorded warm-cache run returned 63 cache hits in 2.82 seconds across 60 catalogue records; this is not presented as a cold-run benchmark.

05 / SYSTEMS THINKING

E-commerce State Synchronization

Failure analysis

The problem. Asynchronous requests can finish out of order, allowing an older response to overwrite state produced by a newer user action.

What I did. I explored request-sequence guards so the application can distinguish the latest request from stale responses instead of treating arrival order as authority.

What came of it. The case study captures a concrete frontend correctness principle. The implementation snippet and reproducible test still need to be attached before claiming verified test evidence.
